# Share with ChatGPT

Share with ChatGPT is a Firefox extension that places the rendered content of the current webpage into a new ChatGPT conversation.

When activated, the extension opens ChatGPT and places the page content into the message composer. The content is not submitted automatically. The user can add a question or instructions before sending the message.

## Why this extension?

Providing ChatGPT with a URL does not guarantee that it receives the same complete rendered page content that is visible in the browser. This extension supplies that content directly to the conversation so that questions, fact-checking, research, summarization, and analysis can be grounded in the page being viewed.

The extension addresses a current integration gap between Firefox and ChatGPT. Future browser or ChatGPT capabilities may make this workflow unnecessary.

## Usage

If you intend to use an authenticated ChatGPT account, sign in to ChatGPT in the same Firefox browser session before using the extension.

1. Open the webpage you want to discuss in Firefox.
2. Open the Firefox menu and select **Share with ChatGPT** to initiate the extension.
3. The extension opens a new ChatGPT conversation and places the webpage content into the message composer.
4. Add your question or instructions to the prepared message.
5. Submit the message when ready.

### Android

On Android, ChatGPT must remain open in Firefox for the extension to work correctly. Firefox must therefore be configured not to hand ChatGPT links off to the ChatGPT Android app.

In Firefox settings, disable opening links in external apps, or otherwise configure Firefox so that ChatGPT opens in the browser rather than the installed ChatGPT app.
